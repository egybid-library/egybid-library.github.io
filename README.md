# مكتبة المكتب المصري للتطوير الصناعي

مكتبة عربية تضم ١٬٩٥٠ مقالًا، مع البحث والتصنيفات والقراءات والمحفوظات والوضع الداكن.

[فتح المكتبة](https://egybid-library.github.io/)

الموقع متاح للجميع دون تسجيل دخول. علامات القراءة والحفظ تبقى في متصفح كل قارئ، مع مزامنة اختيارية عبر Supabase تربط الأجهزة برابط خاص دون حساب للقارئ. إعداد قاعدة البيانات لمرة واحدة في `supabase/setup.sql`؛ تفاصيل التشغيل والربط في README.txt. لنقل البيانات من العنوان السابق استخدم صفحة «نقل بياناتي» في الموقعين.

ملفات الموقع في `docs/`. يُختبر الموقع ويُنشر تلقائيًا عند تحديث الفرع `main`. تفاصيل التشغيل والنقل في [README.txt](README.txt).

لتحديث صور مشاركة المقالات وبيانات المعاينة، شغّل `npm ci` ثم `npm run build`. تُولّد صورة مستقلة بعنوان كل مقال، وتُعاد الاستفادة من الصور التي لم تتغير. الصور موجودة في `docs/assets/article-previews/`، ولا تدخل ضمن تنزيل المكتبة للأوفلاين. التحقق من البيانات والصور عبر `npm run test:sharing`، ومن التوليد التزايدي عبر `npm run test:sharing-images`.
