مكتبة المكتب المصري للتطوير الصناعي — نسخة GitHub Pages

هذه النسخة تضم ١٩٥٠ مقالًا، وصورها، وملفاتها الأصلية، والبحث، والقراءات، والمحفوظات، والوضع الداكن.
الكلمات والأرقام والتواريخ كما في النسخة المنشورة الحالية. تغيير روابط التشغيل فقط لتعمل تحت اسم أي مستودع GitHub.
ملفات الموقع العامة موجودة في docs/، ولا تتضمن مفاتيح وصول أو إعدادات استضافة الموقع السابق.

النشر:
١. رفع هذا المشروع إلى مستودع عام على GitHub، بالفرع main.
٢. Settings → Pages → Build and deployment → Source → GitHub Actions.
٣. يختبر مسار Publish article library الروابط ثم ينشر docs/ تلقائيًا عند رفع تحديث جديد، ويمكن تشغيله يدويًا.
٤. انسخ رابط GitHub Pages الذي يظهر بعد نجاح النشر؛ لا تحتاج القراءات إلى تسجيل دخول.

اختبار محلي:
python3 scripts/verify.py
python3 -m http.server 8880 --directory docs --bind 127.0.0.1
افتح http://127.0.0.1:8880/

الروابط:
تعمل الصفحات في أصل النطاق أو تحت /اسم-المستودع/ دون تعديل يدوي.
الروابط المباشرة للمقالات بصيغتي articles/ID.html وarticles/ID تعمل مع نقل معاملات البحث والترتيب.

سجل القراءة والمحفوظات:
العلامات محفوظة محليًا في متصفح كل قارئ على عنوان الموقع الذي استخدمه.
تغيير العنوان لا ينقلها تلقائيًا. الموقع السابق ما زال يحتفظ بعلاماته، ما لم يمسح المستخدم بيانات المتصفح.
يمكن تصدير سجل القراءة والمحفوظات معًا من صفحة «نقل بياناتي» في الموقع السابق، ثم استيراد الملف في الصفحة نفسها على العنوان الجديد.
الموقع السابق: https://egyptian-industrial-articles-reading.daring-moss-9997.chatgpt.site/profile.html
الموقع الجديد: https://egybid-library.github.io/profile.html

تم تفعيل متابعة أسبوعية عبر Codex كل سبت الساعة ١٠ صباحًا بتوقيت القاهرة. تفحص المجلد ومجلداته الفرعية، وتنبّه بالجديد فقط.
المتابعة تعتمد على اتصال Drive والجهاز المحلي وتطبيق Codex، ولا تعمل داخل GitHub Pages نفسه.
لا تُضاف المقالات ولا تُنشر تلقائيًا؛ الإضافة والمراجعة والنشر خطوات مستقلة وبطلب المستخدم.
مرجع الجرد المحلي: work/drive-monitor/baseline.json في مجلد العمل الرئيسي.
أي إضافة لاحقة ينبغي أن تحتفظ بمعرفات المقالات القائمة لتظل علامات القراءة والحفظ مرتبطة بها.

مصدر النسخة: الموقع الحالي، مع أداة نقل سجل القراءة والمحفوظات.

تحسين سرعة العرض والبحث
------------------------
أول ٢٠ بطاقة كاملة موجودة في HTML، وبيانات التصفح مدمجة معه دون النصوص الكاملة. لا تحتاج هذه البطاقات إلى ملف بيانات خارجي. تُحمّل مقتطفات الصفحات الأخرى عند الحاجة فقط.
البحث في العنوان فوري، والبحث في المحتوى يطلب أجزاء صغيرة تخص الكلمات المطلوبة من search/v-*/ بدل تحميل الفهرس كاملًا. توجد نسختا catalog.json وsearch-index.json للتوافق مع المتصفحات التي ما زالت تستخدم البرنامج السابق؛ لا تطلبهما النسخة الجديدة. الخطوط محلية في docs/assets/fonts/ مع تراخيصها، ويُطبّق الثيم قبل الرسم دون انتظار برنامج خارجي. يبدأ تحميل وزني الخط العربي الأساسيين مبكرًا. تظهر شاشة تحميل خفيفة حتى تجهز المقالات المعروضة ومقتطفاتها وفهرس الأقسام والخطوط والصور وأدوات الصفحة. يُجهّز محرك البحث وجدول توجيهه الصغير قبل عرض الرئيسية؛ أجزاء نتائج البحث تُطلب عند البحث فقط. لا يوجد انتظار مصطنع، ولا تُحمّل النصوص الكاملة لكل الأرشيف مقدمًا. إذا تعطّل التحميل، يظهر زر إعادة المحاولة بعد ١٢ ثانية؛ لا تُعرض صفحة ناقصة تلقائيًا. عند فشل ملف خط تُثبّت خطوط الجهاز، ولا تُخفى الصفحة عند تعطيل JavaScript.
الكتابة تعرض فورًا حتى ٦ اقتراحات من العناوين فقط، دون طلب أجزاء بحث المحتوى. الاقتراحات تحترم القسم وحالة القراءة وتدعم الأسهم وEscape، والاختيار يفتح المقال مباشرة. زر «بحث في العنوان والمحتوى» أو Enter يعرض النتائج الكاملة من العناوين والنصوص؛ لا توجد قائمة نطاق بحث. يشترك البحث الكامل في ذاكرة النتائج والطلبات قيد التنفيذ، ولا تتغير بطاقات النتائج أثناء الكتابة. بعد اكتمال بحث أرسله القارئ، يظهر ملخص بالكلمة والعدد، وينتقل التركيز إلى بداية النتائج مع تمييز مؤقت يحترم إعداد تقليل الحركة. لا يوجد تأخير مصطنع، وتُلغى النقلة إذا بدأ القارئ كتابة بحث آخر.
بعد أي تعديل على archive.json، شغّل من مجلد المستودع:
  node scripts/build-search.mjs
ثم للتحقق من ثبات نتائج البحث وبيانات المقالات:
  node scripts/test-search.mjs
  python3 scripts/verify.py
الملفات الجديدة مشتقة من الأرشيف؛ لا تستبدل archive.json أو ملفات المقالات الأصلية. يتولى سكربت البناء تحديث إصدارات الفهرس والبرامج حتى لا تبقى نسخ قديمة في كاش المتصفح.
