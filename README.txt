مكتبة المكتب المصري للتطوير الصناعي — نسخة GitHub Pages

هذه النسخة تضم ١٩٥٠ مقالًا، وصورها، وملفاتها الأصلية، والبحث، والقراءات، والمحفوظات، والوضع الداكن.
الكلمات والأرقام والتواريخ كما في النسخة المنشورة الحالية. تغيير روابط التشغيل فقط لتعمل تحت اسم أي مستودع GitHub.
ملفات الموقع العامة موجودة في docs/، ولا تتضمن مفاتيح وصول أو إعدادات استضافة الموقع السابق.

النشر:
١. رفع هذا المشروع إلى مستودع عام على GitHub، بالفرع main.
٢. Settings → Pages → Build and deployment → Source → GitHub Actions.
٣. يختبر مسار Publish article library الروابط ثم ينشر docs/ تلقائيًا عند رفع تحديث جديد، ويمكن تشغيله يدويًا.
٤. انسخ رابط GitHub Pages الذي يظهر بعد نجاح النشر؛ لا تحتاج القراءات إلى تسجيل دخول.

اختبار محلي:
python3 scripts/verify.py
python3 -m http.server 8880 --directory docs --bind 127.0.0.1
افتح http://127.0.0.1:8880/

الروابط:
تعمل الصفحات في أصل النطاق أو تحت /اسم-المستودع/ دون تعديل يدوي.
الروابط المباشرة للمقالات بصيغتي articles/ID.html وarticles/ID تعمل مع نقل معاملات البحث والترتيب.

سجل القراءة والمحفوظات:
العلامات محفوظة محليًا في متصفح كل قارئ على عنوان الموقع الذي استخدمه.
تغيير العنوان لا ينقلها تلقائيًا. الموقع السابق ما زال يحتفظ بعلاماته، ما لم يمسح المستخدم بيانات المتصفح.
يمكن تصدير سجل القراءة والمحفوظات معًا من صفحة «نقل بياناتي» في الموقع السابق، ثم استيراد الملف في الصفحة نفسها على العنوان الجديد.
الموقع السابق: https://egyptian-industrial-articles-reading.daring-moss-9997.chatgpt.site/profile.html
الموقع الجديد: https://egybid-library.github.io/profile.html

تحسين سرعة العرض والبحث
------------------------
أول ٢٠ بطاقة كاملة موجودة في HTML، وبيانات التصفح مدمجة معه دون النصوص الكاملة. لا تحتاج هذه البطاقات إلى ملف بيانات خارجي. تُحمّل مقتطفات الصفحات الأخرى عند الحاجة فقط.
البحث في العنوان فوري، والبحث في المحتوى يطلب أجزاء صغيرة تخص الكلمات المطلوبة من search/v-*/ بدل تحميل الفهرس كاملًا. توجد نسختا catalog.json وsearch-index.json للتوافق مع المتصفحات التي ما زالت تستخدم البرنامج السابق؛ لا تطلبهما النسخة الجديدة. الخطوط محلية في docs/assets/fonts/ مع تراخيصها، ويُطبّق الثيم قبل الرسم دون انتظار برنامج خارجي. يبدأ تحميل وزني الخط العربي الأساسيين مبكرًا. تظهر شاشة تحميل خفيفة حتى تجهز المقالات المعروضة ومقتطفاتها وفهرس الأقسام والخطوط والصور وأدوات الصفحة. يُجهّز محرك البحث وجدول توجيهه الصغير قبل عرض الرئيسية؛ أجزاء نتائج البحث تُطلب عند البحث فقط. لا يوجد انتظار مصطنع، ولا تُحمّل النصوص الكاملة لكل الأرشيف مقدمًا. إذا تعطّل التحميل، يظهر زر إعادة المحاولة بعد ١٢ ثانية؛ لا تُعرض صفحة ناقصة تلقائيًا. عند فشل ملف خط تُثبّت خطوط الجهاز، ولا تُخفى الصفحة عند تعطيل JavaScript.
الكتابة تعرض فورًا حتى ٦ اقتراحات من العناوين فقط، دون طلب أجزاء بحث المحتوى. يظهر عدد مطابقات العناوين عند زيادتها عن الستة. أسفل الاقتراحات زران جنبًا إلى جنب: عرض كل نتائج العناوين داخل البطاقات، والبحث في العنوان والمحتوى؛ يتعطل زر العناوين عند عدم وجود مطابقات. يُحفظ نطاق البحث في الرابط، ويبحث Enter في العنوان والمحتوى. لا يوجد زر بحث منفصل خارج الاقتراحات. الاقتراحات والبحث يشملان جميع الأقسام مع احترام حالة القراءة المختارة. بدء بحث يلغي تحديد القسم، واختيار قسم أثناء البحث يعيد تصفّح القسم ويمسح البحث. الاقتراحات تدعم الأسهم وEscape، والاختيار يفتح المقال مباشرة. زر «بحث في العنوان والمحتوى» أو Enter يعرض النتائج الكاملة من العناوين والنصوص؛ لا توجد قائمة نطاق بحث. يشترك البحث الكامل في ذاكرة النتائج والطلبات قيد التنفيذ، ولا تتغير بطاقات النتائج أثناء الكتابة. بعد اكتمال بحث أرسله القارئ، يظهر ملخص بالكلمة والعدد، وينتقل التركيز إلى بداية النتائج مع تمييز مؤقت يحترم إعداد تقليل الحركة. لا يوجد تأخير مصطنع، وتُلغى النقلة إذا بدأ القارئ كتابة بحث آخر.
بعد أي تعديل على archive.json، شغّل من مجلد المستودع:
  node scripts/build-search.mjs
ثم للتحقق من ثبات نتائج البحث وبيانات المقالات:
  node scripts/test-search.mjs
  python3 scripts/verify.py
الملفات الجديدة مشتقة من الأرشيف؛ لا تستبدل archive.json أو ملفات المقالات الأصلية. يتولى سكربت البناء تحديث إصدارات الفهرس والبرامج حتى لا تبقى نسخ قديمة في كاش المتصفح.

القراءة دون إنترنت
------------------
زر «تحميل المكتبة» في الهيدر بجوار أدوات التنقل يفتح تنزيلًا اختياريًا للمقالات الـ١٩٥٠ وصورها والخطوط وفهارس البحث. لا يبدأ تنزيل الحزمة عند فتح الموقع، ويمكن إيقاف التنزيل واستكماله. عند اكتماله يفتح القارئ نفس الرابط في المتصفح نفسه دون اتصال. الملفات الأصلية Word وبيانات الاستيراد القديمة ليست مطلوبة لتشغيل القراءة أو البحث، ولا تدخل الحزمة.
تُعرض مساحة الجهاز والحجم المضغوط التقديري قبل التنزيل. ملفات الموقع على الاستضافة لا تُحذف. تبقى علامات القراءة والمحفوظات في بيانات المتصفح المعتادة؛ إزالة نسخة الأوفلاين لا تمسّها. مسح بيانات الموقع من المتصفح يزيل نسخة الأوفلاين أيضًا.
عند فتح نافذة الأوفلاين أثناء الاتصال، تُعرض إمكانية تحديث النسخة. يقارن التحديث بصمة SHA-256 وحجم كل ملف مع النسخة المحفوظة. الملفات المطابقة تُنسخ محليًا؛ تُنزّل الملفات الجديدة والمتغيّرة فقط، وكذلك أي ملف ناقص أو تالف. تعرض النافذة تقدير حجم التحديث المتبقي. لا تُستبدل النسخة الكاملة القديمة إلا بعد التحقق من اكتمال ملفات الجديدة وتوقيعاتها، وتُستبعد الملفات المحذوفة من النسخة الجديدة. يبقى الاستكمال بعد انقطاع التنزيل مقتصرًا على الملفات الناقصة. الحفظ مرتبط بالمتصفح والجهاز، ويفضّل تجنّب وضع التصفح الخاص. يمكن للمتصفح حذف التخزين عند ضغط المساحة؛ يطلب الموقع إبقاء التخزين بعد اكتمال التنزيل، ولا يعد ذلك ضمانًا.
يُنشئ build-search.mjs تلقائيًا offline-manifest.json ويضيف برنامج الأوفلاين للصفحات. شغّله بعد أي تعديل في ملفات الموقع كي تتطابق توقيعات الحزمة. للتحقق: node scripts/test-offline.mjs.

ترتيب النشر
-----------
عند تساوي تاريخ نشر مقالتين، يُعتبر الأصغر أبجديًا أسبق نشرًا: ترتيب «الأقدم نشرًا» أبجدي تصاعدي داخل اليوم، و«الأحدث نشرًا» أبجدي تنازلي داخله. تُطبّق القاعدة على البطاقات الأولى والبحث والقائمة الجانبية والتنقل بين المقالات، دون تعديل تاريخ أي مقال أو ترتيب سجل الأرشيف المصدر.

يعرض مربع الأوفلاين وقت آخر تنزيل أو تحديث مكتمل بتوقيت القاهرة. يُحفظ الوقت عند اكتمال النسخة فقط، ويظل ثابتًا عند فتح الصفحة أو فشل التحديث. النسخ القديمة التي لا تحتوي وقت حفظ لا يُختلق لها تاريخ، ويظهر الوقت بعد إكمال تحديثها.

المزامنة الاختيارية
------------------
