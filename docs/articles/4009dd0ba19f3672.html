لانّ القصيدة دي من الفلكلور

ومش معروف مؤلّفها

-

يا ابو زين عندك فـ ( ضرب النار )

دي شبابيكك ف الـ ( دار بنّار )

يعني بنّور أو زجاج

دي خد شريطة ف ضرب النار

متولّيّ يا جرجاويّ

يا جرجاويّ يا متولّيّ يا جرجاويّ

-

ناس علي رجوليته ( شارطين )

وكان ف بلده ( شاري طين )

اترجّي وأخد ( شريطين )

-

الدنيا دي غرورة لما تولّي

لو كان علي قطب و 100 وليّ

قال له مالك بيّا يا متولّيّ

-

متولّي كان وجيه والـ ( صورة حلو )

واللي عليه بيـ ( وصّي راحلو )

باسبوع مضي له و ( صرّح له )

-

فتح له الباب يجول ( سلامات )

عضامي علي بعض ( سلّمت )

ليه تاركني وتنـ ( سي اللمّات )

-

جال له يابا بنتك لو إنـ ( تا ربّيتها )

ما ترافجش وتاخد الـ ( طور بيتها )

طب جوم ورّيني ( تربتها )

-

يا أخينا داير ( بكا مالك )

ما كنت جاعد ( بـكمالك )

ياك خدوا من الـ ( بكّ مالك )

-

قال له يا ريت ( راح مالي )

أنا الموت بقي ستر و( رحمة لي )

وجمّالي عاكسني و ( أراح مالي )

-

وف العذاب جلبي ( بربّيه )

علشان يآمن ( بربّيه )

خدوا وطلع ( برّا بيه )

-

جال له قوم اجف علي ( جدمك )

الحظّ اتعدل ( جدّمك )

والسكّة فضيت ( جدّامك )

-

جال يا بيه أنا دمّي فار زيّ العمّال

العمّال هو القطر البخاريّ

ومع أسود عمل الفار عمل

وحدانا سجرة وفيها فرع مال

-

ما فيش غيري لا عمّ ولا خال ليه

أشرب المرار ده والخلّ ليه

أجطعو يا بيه ولا أخلّيه ؟

-

كان القاضي اسمه حسن

راجل عنده فضل وإحسان

جال له صراحة جطعه أحسن

-

أصل إنتا شريف وعملك ( شي يعلّيك )

أبدا ما فيشي ( شي عليك )

-

وهكذا يتجوّل الفلكلور الشعبيّ

في حداق فنّ الواو

ليتحفنا بهذا السحر

-

وطبعا فيه قصيدة تانية مشهورة جدّا

بتاعة ( ليلي ليل يا ليلي يا ليلي )

-

ما أعرفش بردو اسمها إيه

بسّ هيّا مشهورة بالنغمة بتاعة

ليلي ليل يا ليلي يا ليل

-

ياللي إنتا جاي لي ( معاتبني )

ليه بعتني بالخسارة

وحرجت جمحي ( مع تبني )

تهجب ولا جسارة

-

علي حظّي أنا اللي اتـ ( لوى الزان )

لمّا عملته سريري

لو يعجل الجو ( لة وزّان )

جمحك ما يسوي شعيري

-

و 3 بنات [ كلّموني ]

وعزولي راح ( جال لابوهم )

ليهم خدود [ كاللموني ]

يا بخت مين ( جلّبوهم )

-

اعتبرته دلوقتي لمون
